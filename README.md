# Responsive Profile Card — HTML & CSS

This project is a basic **HTML and CSS challenge** from [GreatFrontEnd](https://www.greatfrontend.com/), where I created a **responsive profile card** based on the provided design. The main goal of this challenge was to practice fundamental frontend development skills such as semantic HTML, CSS styling, Flexbox, spacing, typography, borders, backgrounds, and responsive design. The project was built using only **HTML and CSS**, without any JavaScript or external frameworks.

**Challenge:** [Responsive profile Card with HTML & CSS](https://www.greatfrontend.com/projects/s/responsive-profile-card-design-with-html-and-css-39a3cd58 )

**Live Demo:** https://getfrontend.avijeetpaul.com/HTML-Profile-Card/
